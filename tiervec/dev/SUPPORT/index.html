    Support¶

    Experimental and unreleased. The API is not stable and nothing here is wired into a database engine yet. What may change.

    tiervec is an open source library, maintained by HumemAI under the Apache License 2.0. It is experimental: there is no release yet, and the API can change (see docs/STATUS.md).

    Who maintains it¶

    The maintainer is @tae898. Every issue and pull request is assigned to the maintainer when it is opened.

    How to get help¶

    You want to Do this
    Report a bug Open an issue with the bug template. It asks for the JDK, the platform, and whether the Vector API is on.
    Ask how something works Read README.md, docs/DESIGN.md and docs/PROVIDER-CONTRACT.md. If they do not answer it, open an issue with the question label.
    Propose a feature Open an issue with the feature template.
    Report a security problem Follow SECURITY.md. Do not use a public issue.

    What to expect¶

    This is best-effort support from one maintainer. There is no response-time promise, no commercial support, and no hosted service. Bugs that come with a short, runnable reproduction are fixed first.

    Only the code on main is supported. A host that wants to depend on tiervec today should expect the API to change between versions (see docs/ROADMAP.md).
